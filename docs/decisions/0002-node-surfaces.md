# ADR 0002：内容节点与模块边界

日期：2026-11-02；状态：实现。

用户要求：节点下方直接编辑参数，内容铺满节点，Hover 上方工具栏，媒体比例自适应；代码应便于未来开源维护。

决定：保留 PixiJS 内容绘制 + 按需 DOM 控件。以独立纯类型、文档、序列化、布局、空间、交互、渲染、浮层、资源和节点定义模块组织；通过受检查的依赖规则保持边界。核心包提供 index/core/react 三个入口，暂不拆分多个独立发布包。

节点几何独立于临时工具栏/表单。新节点采用自动内容尺寸，旧节点保持已有布局，用户手动缩放进入 manual。模型设置和敏感配置留在 App。

取舍：参数浮层可覆盖附近节点，但不会推动布局；一次只挂载一个表单。视频默认静态封面，一次一个播放器。超长文本使用高度上限，排版精度后续可独立改进。

正式开源许可证、远程发布仍待单独决策，不包含在本次本地研发授权内。
