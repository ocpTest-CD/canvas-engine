# 0.4 接入能力验收

日期：2026-11-03。此记录是开发验证，不是生产 SLA 或新的主观评分。

- 47 项引擎单元测试通过，包括跨语言 fixture、事务重放、远端撤销、运行状态、只读、嵌套数据隔离、bridge 来源转发。
- 构建、模块边界、实际 npm tarball headless/bridge 消费验证通过；NodeNext 声明导入修复。
- 原有 15 个浏览器场景在 Chromium/Firefox/WebKit 通过（Firefox/WebKit 的 CDP touch 两项跳过）；新只读/远端/runtime 与只读媒体预览场景三种浏览器均通过。合计 49 个可执行用例通过、2 项跳过；初次新用例等待初始化不充分，修复后定向复测通过。
- 独立 SDK 实际消费引擎，通过 Chromium/PixiJS → SDK → Go API → PostgreSQL 保存、断网编辑、页面刷新、重开同步与销毁检查。
- 引擎通过 SDK 对接真实后端队列和素材存储；生成采用显式 Mock，不代表真实模型生成效果。

未重复 0.3 性能基准，因此不更新性能数值；尚无移动硬件/原生 renderer/多人协作验收。0.4 的本地事务事件及运行状态是接入能力，业务执行、模型 UI、S3/账号安全仍由后端和宿主负责。旧桌面 Canvas App 没有在本轮替换其打包依赖，也未重新发布。
