# 核心概念

- Node 是有稳定 ID、位置、尺寸和内容引用的工作对象；生成参数属于宿主。
- 世界坐标决定节点和连线；Camera 转成屏幕坐标。NodePanel 和工具栏使用屏幕 CSS 像素，不进入空间索引。
- sizeMode=auto：新媒体按原始宽高适配，普通比例长边默认400画布单位；文本按宽度估算高度，最高420。
- sizeMode=manual：用户拖动尺寸后保留指定大小。媒体保持已知比例。
- 缺少 sizeMode：兼容旧文件，保持原有几何。使用“适配内容”才切换自动模式。
- MediaMetadata 保存原始宽高、MIME、可选时长。缩略图最长边768，仅用于展示，不用于计算源素材比例。
- 图像和视频正文没有外围留白；旧布局或用户手动指定不同画幅时完整 contain，避免默默裁剪。
- 普通点击打开下方面板；移动超过5屏幕像素才形成拖动；双击/预览打开内容编辑器。
- Hover 工具栏有180ms离开宽限，鼠标可通过间隙进入工具栏；面板激活时对应操作保持稳定。
- 同时一个参数面板、一个内容播放器。媒体编辑器关闭会暂停、清除src、释放ObjectURL。
- 浮层、Hover、焦点属于临时 UI 状态，不进入场景文件或撤销历史。
- 音频当前提供按需播放控件，未实现真实波形缓存；不显示伪造波形。

键盘：Tab在节点间切换，F2进入当前节点下方参数，Esc收起并回到画布。点击视频中央播放图标直接预览，点击其他区域打开参数。preferredAspectRatio用于无结果节点的预设画幅，实际媒体加载后使用真实尺寸。
